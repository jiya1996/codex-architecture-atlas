源码与说明

本演示沿用已核对的 Codex 源码版本 85c2d4d9。动画是讲解示例，不是实际运行日志；可以跳过工具，或重复多轮模型与工具调用。

模型服务以 OpenAI 云端为例。SSH 整体任务在远程主机运行；Core 也可连接独立远程执行器。Cloud 使用云端 Agent 运行时，其内部部署拓扑不由开源 Core 源码证明。权限与沙箱按配置生效，MCP 服务还受其自身授权约束。

首页明确标出 App Server 与 Codex Core（核心）。本地与 SSH 展示这些组件；Cloud 沿用节点表达对应职责，其具体内部实现未验证，不能据此认定与开源实现相同。三个模式仅切换部署归属框，节点与连线保持不变。

第二张按七类职责归纳，不代表七个同级源码包。模型通信是 Core 内的通信能力，模型本身在 Core 外部。
